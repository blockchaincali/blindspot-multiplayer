# BLINDSPOT — Cooperative Multiplayer Maze Game

A real-time browser-based cooperative maze game built for the Handshake × OpenAI game challenge.

Players join with a room code, collaborate as Runner and Scouts, place navigation beacons and escape a randomized maze before time runs out.

## Run

```bash
npm start
```

## Tests

```bash
npm test
```

## Deploy

Use Render as a Node web service with `npm install --omit=dev` and `npm start`, healthcheck `/healthz`.
